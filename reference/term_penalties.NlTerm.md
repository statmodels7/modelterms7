# Penalties of a Nonlinear Term

The penalties the sub-terms of the subformulas declare, each under the
key `parameter::subterm` and covering that sub-term's coefficients in
the term's own numbering. The list is empty when there are none, and for
a specification, whose parameters a formula does not name until the data
say which of them the data supply.

## Arguments

- term:

  A built
  [`NlTerm`](https://statmodels7.github.io/modelterms7/reference/NlTerm.md).

- ...:

  Unused.

## Value

A list of entries, as
[`term_penalties`](https://statmodels7.github.io/modelterms7/reference/term_penalties.md)
documents.

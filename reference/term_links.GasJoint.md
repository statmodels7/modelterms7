# The Charts of a Joint Score-Driven Filter

Returns the links of every term of the filter, named as
[`term_params()`](https://statmodels7.github.io/modelterms7/reference/term_params.md)
of the joint filter names the parameters.

## Arguments

- term:

  A
  [`GasJoint()`](https://statmodels7.github.io/modelterms7/reference/GasJoint.md).

- ...:

  Unused.

## Value

A named list of linkfunctions7 links.

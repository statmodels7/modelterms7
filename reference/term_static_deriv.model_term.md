# No State, No Propagation

The base method returns `NULL`: an ordinary term's contribution at one
observation reads that observation alone.

## Arguments

- term:

  A term.

- curv, X, psi:

  Ignored.

- ...:

  Ignored.

## Value

`NULL`.

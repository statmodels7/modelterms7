# Base Method of term_static_deriv()

The base method returns `NULL`: an ordinary term's contribution at one
observation reads only that observation.

## Arguments

- term:

  A term.

- curvature, X, psi:

  Ignored.

- ...:

  Ignored.

## Value

`NULL`.

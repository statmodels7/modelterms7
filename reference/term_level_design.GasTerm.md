# The Design of a Developed Level

Returns the design of the development of `omega` when it carries one,
with the columns named after the coordinates so that a fitting layer can
compare its span with the equation's, and `NULL` for a scalar level.

## Arguments

- term:

  A built
  [`GasTerm()`](https://statmodels7.github.io/modelterms7/reference/GasTerm.md).

- ...:

  Unused.

## Value

A numeric matrix or `NULL`.

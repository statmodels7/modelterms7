# The Design of a Developed Level

The design of `omega`'s development when it carries one, its columns
named after the coordinates, so a fitting layer can compare its span
with the equation's; `NULL` for a scalar level.

## Arguments

- term:

  A built
  [`GasTerm()`](https://statmodels7.github.io/modelterms7/reference/GasTerm.md).

- ...:

  Unused.

## Value

A numeric matrix or `NULL`.

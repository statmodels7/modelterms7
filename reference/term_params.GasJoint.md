# The Parameters of a Joint Score-Driven Filter

Returns the parameters of every term of the filter, in the order of the
terms, each prefixed by the distribution parameter of its term, as in
`mu.omega`.

## Arguments

- term:

  A
  [`GasJoint()`](https://statmodels7.github.io/modelterms7/reference/GasJoint.md).

- ...:

  Unused.

## Value

A character vector.

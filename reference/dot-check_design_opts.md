# Check a Term's Storage and Contrasts

Check a Term's Storage and Contrasts

## Usage

``` r
.check_design_opts(sparse, contrasts, what = "this term")
```

## Arguments

- sparse:

  What the constructor was given.

- contrasts:

  What the constructor was given.

- what:

  The term's label, for the message.

## Value

A list of the two, validated.

# modelterms7: Model Terms as Objects for Formula-Based Modeling

Model terms as 'S7' objects: the mapping from a data frame to a
design-matrix block, the penalty attached to the block's coefficients,
and the metadata a fit reads, with a formula interpreter that recognizes
term constructors by what they return rather than by name, so
user-defined terms work in formulas without registration. Includes the
unpenalized parametric term and the censored-response constructor. Part
of the 'statmodels7' toolkit.

# Penalties of a Joint Score-Driven Filter

Returns an empty list: the terms of a joint filter carry no subformula,
and their scalar parameters are unpenalized.

## Arguments

- term:

  A
  [`GasJoint()`](https://statmodels7.github.io/modelterms7/reference/GasJoint.md).

- ...:

  Unused.

## Value

An empty list.

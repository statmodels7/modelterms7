# The Empty Parameters of a Driver

A
[`GasDriver()`](https://statmodels7.github.io/modelterms7/reference/GasDriver.md)
has no parameters: its parameters, links, start, penalties, components,
level parameter and readable quantities are empty.

## Arguments

- term:

  A
  [`GasDriver()`](https://statmodels7.github.io/modelterms7/reference/GasDriver.md).

- zeta:

  Unused.

- ...:

  Unused.

## Value

An empty vector or list of the type the generic returns.

# The autoplot() Generic of ggplot2

The generic `autoplot()` belongs to ggplot2, which this package suggests
and does not import. The methods written on it here are registered by
[`S7::methods_register()`](https://rconsortium.github.io/S7/reference/methods_register.html)
when ggplot2 is loaded.

## Usage

``` r
autoplot
```

## Format

An object of class `S7_external_generic` of length 4.

## Value

An S7 external generic, the description of
[`ggplot2::autoplot()`](https://ggplot2.tidyverse.org/reference/autoplot.html)
that
[`S7::method()`](https://rconsortium.github.io/S7/reference/method.html)
registers methods on.
